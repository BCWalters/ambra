Book details

Real covers beside generated covers

Three credited Standard Ebooks covers mix with three fictional fallback examples. Existing cover art is contained, not cropped, recolored, or replaced.

Discovery is a main action

Find books stays beside Import above the collection, including empty and small libraries. A centered modal keeps focus on discovery without moving the grid. Close or Escape returns to the library.

Single-book removal

Focus a book and press Delete or Backspace to request removal, or use Remove from library at the bottom of Book details. No selection mode or duplicate actions menu; every removal requires confirmation.

Controls preview only; no audio is loaded.
The Quiet Coast

The headland

Before the village

The morning road ran between low walls. We left the last house behind and followed the pale line of the coast.

The headland

At the bend in the path, the village disappeared behind us. All that remained was the sound of our footsteps and the long, even breath of the sea.

I had brought a notebook with the intention of recording the names of things: the birds along the wall, the flowers between the stones, the distant shape of an island. But the page stayed empty.

There was no need to name everything before I could notice it. We stopped beside the low gate, where the grass had turned silver in the wind, and watched a boat make its patient way toward home.

Later, I wrote down just one thing: leave enough room in the day to be surprised.

The harbour

By the harbour, ropes tapped against the masts. We sat on the warm steps and watched the tide uncover another line of stones.

Evening light

On the way back, the windows caught the last light. The road was familiar now, but we walked it more slowly.

Bookmarks

Read along

Two settings scopes

Aa opens Book options for typography and layout. The gear keeps the same Ambra-wide values everywhere: reading preferences lead and open expanded in the reader; interface theme and language lead in the library. This changes presentation, not persistence scope.

One reference panel at a time

Library and Contents open on the left; Search, Annotations, and Book details open on the right. Opening one replaces the other. Contents, Annotations, and Search start pinned here for layout review; unpin to try temporary flyouts. This preview default does not change the app's pin defaults.

Your notes come first

Notes lead each entry; the quoted passage provides quieter context underneath. Edit or add a note in place, then Save or Cancel. Drafts survive panel/filter changes. Edits stay in memory only; Reset sample or reloading restores the original notes.

Reader interaction boundary: page positions and chapter ranges are simulated across 157 pages. Scrubbing and both bookmark entry points update the same position and show an original chapter excerpt, not 157 paginated pages. The headland's passage anchors share sample page 45; chapter starts are 1, 43, 78, and 120. Bookmark flags occupy one fixed-height row. Screen-space collisions form a counted group centred on its page range; its chooser shows at most five destinations, then opens Annotations for the full list. Isolated flags navigate directly. The bookmark sample selector replaces only sample bookmarks. Search covers the original headland passage. Font choices are representative. Reading mode, page-turn animation, and one-page layout remain disabled; upcoming chapter bands can be shown or hidden in Ambra settings. Production retains known book-wide target page numbers and leaves unknown numbers absent. Reader auto-hide remains an implementation requirement; chrome stays visible for review. Read-along appears automatically paused when available; controls change preview states only, with no audio loaded or synthesized. No extension settings or publication content are changed.

Small window / Same Ambra

Compact, not cramped.

Find books opens a new local preview tab with discovery already open. Import stays beside it. Neither action is hidden below the collection. The book list scrolls independently of these actions.

Search and Sort stay together. Sort offers the same choices as the full library and in-reader library, with one shared in-memory order across these views. Try opening a sample book or switching the shared theme above.

This is a browser mockup of popup geometry, not an actual Chrome action popup. Native sizing and all nine locales will need implementation validation.

Amber identity, accessible emphasis

Ambra uses the icon's golden-orange accent for filled actions, with dark labels. A deeper amber handles text and focus on light surfaces; surfaces themselves stay quiet.

Three action levels. One visible focus rule.

Use Tab to inspect focus. Selected state and keyboard focus remain distinct.

Review boundary: standalone HTML/CSS study, not production Fluent UI components. Three real cover images are copied locally from credited Standard Ebooks editions; no book text or personal library is loaded. Other titles, covers, notes, and the reader passage are original fictional demo material. Opening any cover shows that same labeled sample passage, not the selected work's text. Nothing changes your extension, release files, or stored preferences. Theme names/default and browser-following appearance reflect your feedback; exact colors, the resume row, and popup list remain proposals. App settings now change the shared preview theme; language selection is displayed but disabled because this study is English-only. The help dialog shows the existing reader shortcut reference, not functioning reader commands in this mockup. Diagnostic copying identifies this prototype, never the installed extension. Unmodeled settings remain supported in the product; their omission here is not a removal proposal. Cover sources and rights.

Find books

Browse EPUB collections and books to buy. Source links open in a new tab.

Standard Ebooks

Edited public-domain classics. On a book's page, choose Advanced epub.

Project Gutenberg

Free literature and classics. Choose an EPUB or EPUB3 download.

ReadBeyond

Books with recorded narration. Choose Download for an EPUB with audio, not Read+Listen.

eBooks.com

DRM-free EPUBs to buy. Choose a DRM-free EPUB edition and download it after purchase.

Add a book to Ambra

  1. Choose an EPUB download, not Kindle or PDF.
  2. Ambra may open a direct EPUB link. If the file downloads instead, return to the library, select Import book, and choose the saved file.

Check each book's license and local copyright rules. Free does not always mean public domain. Your library stays on this device; Ambra does not browse these sites for you.

Prototype: source links are real; importing books is not connected here.

Remove book?

    This removes the book from Ambra, including saved reading progress, book settings, bookmarks, highlights, and notes. Original EPUB files on disk are not deleted. This cannot be undone.

    Prototype only: this changes the sample library in memory. It cannot access your books. Reset sample restores demo data; it is not a proposed app undo.

Books first. Everything else, quieter.

Four ways to make the small window feel like a place to return to reading, rather than a collection of controls. The new D option removes the separate lists entirely. Only the compact library is being explored; the full library and reader are unchanged.

Standalone sample only. Nothing reads your files, changes Ambra, or stores preferences. These are choices to review, not a production implementation.

Appearance follows your browser.

Try D: just keep reading.

D keeps a small, clickable Continue Reading card and a flat list underneath, without tabs, categories or an All list. The whole card resumes reading, so there is no separate button row. Find & sort starts collapsed; Find books is the prominent bottom action beside Import book, including for an empty library. Full library is a quiet link in the top header, just before the options menu.

The original A, B and C remain for comparison. A adds reading-list shortcuts, B emphasizes those lists, and C favors cover recognition.

In every option, Find & sort is a closed, keyboard-accessible disclosure. Search state stays visible when it is closed, with an immediate clear action. Import, discovery, settings and help remain available without becoming the visual center.

Try a list with no books, a search with no results, sorting by author, opening a book, importing an original sample book, and Escape from the disclosures/dialog. Changes are in memory and shared sample books only; each option keeps its own list/search/order.

English-only study. Fixed-height frames illustrate popup geometry, not a native Chrome action popup. Dialogs belong to this comparison page. Real popup sizing, all nine locales, visual/AT behavior, real files and persistence still need implementation validation after an owner decision. No local browser tests were run for this study.

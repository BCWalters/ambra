# Annotations and Bookmarks

## Save and revisit a bookmark

Use the reader toolbar’s bookmark button, or **Mod+B**, to add or remove a bookmark at your current position. **Mod** means Command on Mac and Control elsewhere.

Open **Bookmarks and highlights → Bookmarks** to browse saved places. Choose a card’s title to return to its position; hover a long title to read it in full. Remove a bookmark with its remove control. After keyboard deletion, focus moves to a neighboring bookmark, or stays in the empty tab when none remain.

The page badge refers to the book-wide page in your current layout, not a permanent printed page number. It updates when text size or page width changes:

- **Finding page…** means pagination is still being measured.
- **Page unavailable** appears in scrolling mode or when the saved position cannot be placed.

These changes do not rewrite saved labels or locations. Publisher bookmarks have a **Publisher note** tag and cannot be deleted. Blue ribbons also mark bookmarks on the [progress bar](book-navigation.md#move-along-the-progress-bar) once pagination is ready.

## Highlight text and add a note

1. Select a passage in the book.
2. Choose a highlight color or underline in the selection toolbar. Choose **Add note** to create a highlight and start a note together.
3. Write your note and choose **Save**, or **Cancel** to dismiss your edits.

Open an existing highlight to change its color, add or edit a note, or delete the highlight. You can also revisit highlights and manage their notes in **Bookmarks and highlights → Highlights**.

Popup controls stay above the page controls while you work, and typing stays in the note editor rather than turning pages. Publisher footnote popups are read-only; see [Reading tips](reading-tips.md#read-popup-notes-without-losing-your-place).

## Export or import annotations

In **Bookmarks and highlights**, use **Export** to save your highlights, text notes, bookmarks, and bookmark labels as an **EPUB Annotations 1.0 JSON file** (`… - annotations.json`). The download arrow identifies Export; the upload arrow identifies **Import**.

To restore or bring in annotations, open the matching book, choose **Import**, and select a compatible JSON file. Use the same book or edition for best results. Ambra skips unsupported locations and detected duplicates; imported highlights use yellow, and compatibility varies between annotation tools. If import reports that the file belongs to another book or does not line up, check the edition and the file you selected.

Annotation exports are separate from the EPUB. Keep both as backups: Ambra’s library and reading data are local to your browser profile, without automatic cross-device sync. Exports may contain private notes and quoted text, so review them before sharing.
